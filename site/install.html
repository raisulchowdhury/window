INSTALL

Install Window in about two minutes.

Download it, move it to Applications, and allow it once in System Settings. This version isn’t notarized by Apple, so macOS asks you to confirm the first time.

Download for Mac View the source

MACOS 26 OR LATER · FREE · SHA-256: ON GITHUB

  1. 1

    Download

    Download the Window zip file with the button above, or from the latest release on GitHub. It’s named like Window-1.0.1.zip.

    Want to check the file (step 6)? Keep the zip. Safari unzips downloads and removes the zip unless you turn off Safari > Settings > General > Open “safe” files after downloading.

  2. 2

    Unzip

    Double-click the zip in your Downloads folder. You get Window.app. If Safari already unzipped it, it’s in Downloads.

  3. 3

    Move it to Applications

    Drag Window.app to the Applications folder in the Finder sidebar. Do this before you open it.

  4. 4

    Open it the first time

    Double-click Window in Applications. macOS warns that it can’t check Window for malicious software. The exact words depend on your macOS version. Click Done, not Move to Trash.

    Right-clicking the app and choosing Open no longer gets past this warning on recent macOS. Use System Settings instead.

  5. 5

    Allow it in System Settings

    Apple’s steps for macOS Tahoe 26:

    FROM APPLE SUPPORT · OPEN AN APP BY OVERRIDING SECURITY SETTINGS

    1. On your Mac, choose Apple menu > System Settings, then click Privacy & Security in the sidebar. (You may need to scroll down.)
    2. Go to Security, then click Open. You’ll see a line about Window there.
    3. Click Open Anyway. This button is available for about an hour after you try to open the app. If it’s gone, open Window again and come back.
    4. Enter your login password, then click OK.

    Window opens in the menu bar at the top right of your screen, not in the Dock. From now on it opens like any other app.

  6. 6

    Check the download OPTIONAL

    The SHA-256 checksum is a fingerprint of the file. If yours matches the one in Window-1.0.1.zip.sha256 on the GitHub release, you have the exact file that was published. Open Terminal and run:

    cd ~/Downloads
shasum -a 256 Window-1.0.1.zip

    Use your file’s real name. The long code it prints must match exactly. With Window-1.0.1.zip.sha256 in the same folder, shasum -a 256 -c Window-1.0.1.zip.sha256 prints OK when it matches. If it doesn’t match, delete the zip and don’t open the app.

WHY MACOS WARNS YOU

macOS checks apps from the internet with Apple. A developer pays for an Apple Developer membership, signs the app and sends it to Apple to scan. That’s called notarization. Window is a free side project, and this version isn’t notarized, so macOS can’t vouch for it and asks you to decide.

You don’t have to take Window on trust. The source code is public on GitHub, so anyone can read what it does or build it themselves. Window has no account, no analytics and no server. Only download it from this website or its GitHub releases page.

WHAT THE DOWNLOAD DOESN’T INCLUDE

  • The desktop widget. The widget and the app need a shared space to pass the plan between them, and macOS only gives that to apps signed with an Apple developer team. Build Window from source with your own team to get it.
  • Automatic updates. Download the new version and replace the old one in Applications. macOS may ask you to allow it again.

The first time you start a watch, macOS asks whether Window can send notifications. Allow them to get the wrap-up and leave alerts.

UNINSTALL

  • Click Window in the menu bar, click the gear at the bottom left of the panel, and choose Quit Window. If Open at Login is ticked in that menu, untick it first.
  • Drag Window from Applications to the Trash.
  • To remove your saved places and settings too, choose Go > Go to Folder in Finder, enter ~/Library/Containers/xyz.raisul.window.app, and move that folder to the Trash.
